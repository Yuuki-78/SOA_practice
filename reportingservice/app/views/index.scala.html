@() @main("Reporting Service") {

Welcome to Reporting Service

Service đang chạy trên port 9003

Available APIs:

Order Reports:

  • GET /reports/orders - Lấy danh sách tất cả báo cáo đơn hàng
  • GET /reports/orders/:id - Lấy chi tiết báo cáo đơn hàng
  • POST /reports/orders - Tạo báo cáo đơn hàng mới (tự động tính toán từ OrderService)
  • DELETE /reports/orders/:id - Xóa báo cáo đơn hàng

Product Reports:

  • GET /reports/products - Lấy danh sách tất cả báo cáo sản phẩm
  • GET /reports/products/:id - Lấy chi tiết báo cáo sản phẩm
  • POST /reports/products - Tạo báo cáo sản phẩm thủ công
  • DELETE /reports/products/:id - Xóa báo cáo sản phẩm

Tính năng:

  • ✓ Tự động tính toán doanh thu, chi phí, lợi nhuận
  • ✓ Tích hợp với ProductService và OrderService
  • ✓ Báo cáo theo đơn hàng và sản phẩm
  • ✓ JWT Authentication

Lưu ý: Tất cả các API yêu cầu JWT token trong header Authorization

}
